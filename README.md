# SancaMobi

Plataforma de mobilidade urbana exclusiva para São Carlos - SP.

## Arquitetura
- apps/passenger — aplicativo do passageiro (Expo + React Native + TypeScript)
- apps/driver — aplicativo do motorista (Expo + React Native + TypeScript)
- apps/admin — painel operacional (React + Vite + TypeScript)
- functions — backend Firebase Functions
- packages — tipos, UI e serviços compartilhados

## MVP
1. Cadastro e autenticação
2. Cadastro/aprovação de motoristas e veículos
3. Solicitação de corrida
4. Cálculo de tarifa
5. Oferta para motoristas próximos
6. Aceite seguro da corrida
7. Rastreamento em tempo real
8. Início/finalização
9. Avaliações
10. Histórico
11. Painel administrativo
